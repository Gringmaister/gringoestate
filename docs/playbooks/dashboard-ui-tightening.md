# Playbook · Dashboard UI Tightening

## Goal
Reduce fluff and increase action density.

## Sequence
1. identify redundant panels
2. collapse context copy
3. move hard metrics to the first row
4. merge execution surfaces into one main quadrant
5. reduce labels to short operational nouns
6. retest visual hierarchy in code

## Questions to ask the UI
- what matters now?
- what can the user click now?
- what can be removed without hurting action?

## Anti-patterns
- roadmap blocks on the main surface
- many medium cards instead of one strong Ops block
- long explanatory copy inside the dashboard
- premium styling without operational value
